# CBS ranking references

Updated: 2026-09-28. Scope: manual reference for weekly and dynasty decisions.

Use [CBS weekly rankings](https://www.cbssports.com/fantasy/football/rankings/) when reviewing start/sit decisions and [Heath Cummings's dynasty rankings](https://www.cbssports.com/fantasy/football/news/dynasty-fantasy-football-updated-rankings/) when reviewing long-term roster or trade decisions.

Check the named analyst, ranking period, scoring assumptions, and visible update date each time. Link to the specific source when citing an opinion. If freshness or format is unclear, say so; do not present it as verified current advice.

The CLI continues to calculate weekly projections using league scoring and to use FantasyCalc for dynasty prices. CBS opinions can inform a manual discussion of close choices or market disagreements. A published rank does not become projected points, a trade price, or an automatic lineup override. Existing eligibility, injury, and game-lock constraints still apply.

No ranking scraper, provider API, expert-consensus calculation, new command flag, or automatic tie-breaking is part of this scope.
